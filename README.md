# Advanced Library Management System (C++ with SQLite)

This is a **console-based Library Management System** developed using **C++** and **SQLite**. It allows users to manage a collection of books with functionalities to **add**, **borrow**, **return**, **search**, and **display** books efficiently.

---

## 📌 Features

- ✅ Add new books with title, author, and unique numeric ISBN
- 📖 Borrow and return books with real-time availability tracking
- 🔍 Search books by title, author, or ISBN
- 📋 Display all books with status shown as **Available** or **Not Available**
- 🧠 Uses SQLite for persistent local database storage
- 📈 Indexed columns for faster search performance

---

## 🛠 Technologies Used

- **C++** (Standard C++11)
- **SQLite3** (Embedded database)
- **Command-Line Interface (CLI)**
